# SimpleQuickKeys

[English](README.md) | **中文**

> Minecraft **纯客户端**模组：一个快捷键呼出卡片式快捷面板，把常用的物品、按键功能和指令集中到一处。
> 键盘按键不够用？每个格子都有**独立的虚拟键**；面板还能直接调用其它模组的功能 —— 包括那些原本没有单独按键的热键。

## 功能

- **单键呼出**：默认 `G` 开/关面板，`Esc` 关闭；按键可在「选项 → 控制 → 按键绑定」里修改
- **卡片面板**：9 列 × 3 行，每页 27 格，共 3 页 81 格；底部箭头或滚轮翻页；16:9 切角造型、半透明面板，窗口变小自动切换小尺寸布局
- **点击即触发**：点格子直接调用功能，不依赖该功能是否绑定快捷键；潜行 / 疾跑等长按功能自动变成开关（卡片亮起并显示指示条）
- **支持其它模组的快捷键**：装了 Tweakeroo / MiniHUD / Litematica 这类 malilib 系模组时，它们的热键会出现在键位选择界面里，点格子就能**直接触发该功能本身**，不必再给格子单独设一个按键；没装这类模组时界面照常工作
- **键位界面按来源分栏**：左侧「来源」栏第一项是原版键位，之后每个模组各占一栏（JEI、FTB…），无法归类的放进「其它」；来源栏带独立搜索框，可按模组名、分类名或功能名筛选
- **右侧按分类分组**：选中一个来源后，它的功能按分类分组显示，每组带小标题
- **绑了热键的格子看得见**：卡片、悬停提示、编辑界面都会显示该热键的**功能名**；万一解析不出来（模组被移除、热键改名），会显示「未知热键 + 原始标识」，而不是变成空白
- **快捷指令**：每格可填一条指令（如 `home`、`gamemode creative`），填了就优先执行；输入时提供与聊天栏一致的指令补全
- **物品图标**：任意物品可作为图标，内置关键词搜索选择器
- **整块面板可调色**：R / G / B 加透明度，面板底色随你调
- **每个格子也能单独调色**：同样含透明度，用来区分不同格子
- **可放自己的背景图**：把 png / jpg 放进 `config/key_panel/backgrounds/`，在游戏里挑选即可；建议 16:9，其它比例会按比例裁剪铺满；界面里有「打开文件夹」「刷新」按钮和缩略图网格，点一下选用、再点一下取消
- **悬浮提示**：鼠标移到卡片上显示完整名称与触发方式
- **纯客户端**：单人 / 多人皆可，服务端无需安装

## 使用方法

### 打开面板

游戏里按 `G`。按键可在**选项 → 控制 → 按键绑定**的「快捷功能面板」分类里修改。`Esc` 关闭面板。

### 使用格子

- **左键**点格子 → 触发功能。指令、其它模组的热键、普通游戏功能都可以放上去。
- **右键**点格子 → 编辑。弹窗里可以改 **物品ID**、**名称**、**逻辑按键**、**快捷命令**：
  - 「选择图标」= 按关键词搜索物品
  - 「选择键位」= 打开键位选择界面挑一个功能（见下文）
  - 「清空格子」= 清空该格
- 绑定了其它模组热键的格子，弹窗里会用一个只读框显示该热键的功能名。

### 调色、互换与背景图

点面板底部的 **「edit」** 按钮，面板下方会展开编辑卡片（右键点一下格子即可退出）：

- **左边**：「格子 / 背景 / 图片」三个按钮，决定你现在编辑的是选中格子的卡片、整块面板，还是打开背景图选择界面。
- **右边**：**R / G / B / A** 四行滑条，调当前目标的颜色与透明度；最右边的方形色块显示效果，点一下恢复默认颜色。
- 在「格子」模式下，依次点两个格子可以互换它们的内容。

### 用其它模组的热键

右键格子进入编辑，点「选择键位」，在左侧**「来源」**栏里选中那个模组（也可以直接在来源搜索框里打字），右侧就会按分类列出它的功能，点一下即填入正在编辑的格子。来源是 malilib 系模组（Tweakeroo / MiniHUD / Litematica 等）时，以后点这个格子就会直接执行该功能，不需要给它另设按键。

### 相关文件

都在 `config/key_panel/` 下：

- `slots.json` —— 每格的内容（首次打开面板自动生成），可直接编辑或备份
- `background.json` —— 面板颜色与正在使用的背景图
- `backgrounds/` —— 你放的背景图（png / jpg）

## 已知限制

- **按住型热键只能瞬按一下。** malilib 系模组的热键会执行它自己的动作，但按住型热键从面板触发时只是按一下再松开，不会一直保持按住。
- **鼠标绑定的热键可能无效。** 直连不可用时只能退回模拟按键处理，此时鼠标键、鼠标与键盘的组合键可能不生效。
- 极少数游戏功能无法被模拟。遇到了欢迎到 [Issues](https://github.com/TrZeal/Simple-Quick-Keys/issues) 反馈具体的模组或功能。
- **服务器上的指令**受权限限制（例如 `gamemode` 需要 OP）。
- **不会破坏你自己的按键。** 面板只在触发的一瞬间临时借用按键，用完立即还原。

|---|---|---|
| 1.19.2 | Forge | 17 |
| 1.20.1 | Forge | 17 |
| 1.21.1 | NeoForge | 21 |

三个版本只装其中一个：把对应你游戏版本的 jar 放进 `.minecraft/mods/`。模组是纯客户端的，单人 / 多人皆可，服务端不需要安装。
