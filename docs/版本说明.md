# 更新日志

## 1.0.0

首个正式版本。

**支持的平台**

| 文件 | Minecraft | 加载器 | 需要 Java |
|---|---|---|---|
| `SimpleQuickKeys-1.19.2-forge-1.0.0.jar` | 1.19.2 | Forge | 17 |
| `SimpleQuickKeys-1.20.1-forge-1.0.0.jar` | 1.20.1 | Forge | 17 |
| `SimpleQuickKeys-1.21.1-neoforge-1.0.0.jar` | 1.21.1 | NeoForge | 21 |

**功能**

- 单快捷键（默认 `G`）开关面板，`Esc` 关闭
- 9 列 × 3 行卡片面板，每页 27 格，共 3 页 81 格；支持箭头与滚轮翻页；窗口尺寸变化时自动切换三档布局
- 物品图标关键词搜索选择器（16×9 网格，滚动条可拖拽）
- 逻辑按键选择器：从游戏全部功能中挑选
- 快捷指令：每格可绑定一条指令，输入时提供指令补全
- 虚拟按键：可将任意功能（含其它模组的功能）绑定到面板格子触发
- 开关类功能（潜行、疾跑等）显示为开关状态
- 移动槽位：互换两个格子的内容
- 悬浮提示：显示卡片完整名称与触发方式
- 纯客户端模组，服务端无需安装
